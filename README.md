# echoes-forgotten-kingdom-version2
Echoes of the Forgotten Kingdom — a first-person adventure game.  Players awaken in an ancient kingdom, now reclaimed by lush nature. To open the final gate, they must explore various regions, discover relics, and solve age-old puzzles
